About

I'm a software developer based in Bengaluru, originally from Tamil Nadu, currently working at Wyzmindz Solutions. My day-to-day spans enterprise web application development — building frontend interfaces in Angular, backend services in Django and FastAPI, and the REST APIs that connect them.
